# M-9 — `ringtone.caf` referenced in CallKit config but not in bundle — silent incoming call

## Problem

`CallManager.swift` configured the `CXProviderConfiguration` with a custom ringtone:

```swift
config.ringtoneSound = "ringtone.caf"
```

`CXProviderConfiguration.ringtoneSound` expects the filename of a `.caf`, `.aiff`, or `.wav` audio file present in the **main app bundle**. If the file is absent, CallKit silently ignores the setting and plays **no ringtone at all** — the incoming call screen appears with no audio cue.

`ringtone.caf` was never added to the Xcode project's target (not present anywhere in `ios/Runner/`). The app has `audio/ringtone.mp3` as a Flutter asset (used by `AudioPlayer` for the software ringtone), but Flutter assets are not accessible from the native iOS bundle via `ringtoneSound`.

Result: When a call arrived via VoIP push and the native CallKit screen was displayed, the phone was silent — no ringtone. The user had to physically look at their screen to notice the incoming call.

## Fix

**File**: `ios/Runner/CallManager.swift`

Set `ringtoneSound = nil` to use the iOS system default ringtone:

```swift
// BEFORE — referenced a non-existent file → silent CallKit
config.ringtoneSound = "ringtone.caf"

// AFTER — nil uses the iOS system default ringtone
config.ringtoneSound = nil
```

## Adding a Custom Ringtone (Optional Future Step)

To restore a custom ringtone:
1. Convert `assets/audio/ringtone.mp3` to `.caf` format: `afconvert -f caff -d LEI16 ringtone.mp3 ringtone.caf`
2. Drag `ringtone.caf` into the Xcode project under `Runner/`, ensuring **"Add to target: Runner"** is checked.
3. Verify it appears in `Runner` → Build Phases → Copy Bundle Resources.
4. Restore: `config.ringtoneSound = "ringtone.caf"`

## How It Works

`CXProviderConfiguration.ringtoneSound = nil` tells CallKit to use the system's default incoming-call ringtone (the same sound used by the native Phone app). This is always present and never silent, ensuring the user hears the phone ring on every incoming call — regardless of the app's audio asset configuration.
